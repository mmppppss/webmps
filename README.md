
# 📰 InfoCamiri

https://infocamiri.rf.gd

**InfoCamiri** es un medio digital local diseñado para informar, conectar y dar voz a la comunidad de **Camiri, Bolivia**.  
El proyecto nace con el objetivo de ofrecer noticias rápidas, anuncios locales y un espacio digital accesible para todos.

---

## 🚀 Características principales

- 🌐 Sitio web ligero y rápido con diseño minimalista.
- 📱 Totalmente responsive (se adapta a móviles, tablets y PC).
- 📰 Secciones de noticias locales: sociedad, deportes, cultura, economía.
- 📣 Espacio para **anuncios locales** (negocios, eventos, clasificados).
- 🔒 Backend simple en **PHP** para manejar artículos.
- 🎨 Estilo adaptado a la paleta **blanco + celeste**, inspirado en la bandera de Camiri.

---

## ⚙️ Tecnologías utilizadas

- **Frontend:** React, CSS3 (Tailwind), JavaScript.
- **Backend:** PHP (API simple).
- **Base de datos:** MySQL/MariaDB.

---

## 🖼️ Diseño y estilo

- 🎨 Paleta de colores:  
  - **Celeste principal:** `#4fc3f7`  
  - **Celeste oscuro:** `#0288d1`  
  - **Blanco:** `#ffffff`  
  - **Negro suave (texto):** `#1a1a1a`  

- 🖋️ Tipografía: *Computer Modern Typewriter* + Sans Serif de fallback.
